4. Data Flow & Security Sequence

sequenceDiagram participant V as Victim/Complainant participant UI as Frontend Dashboard participant API as FastAPI Backend participant PII as PII Anonymizer participant AI as AI Analysis Engine participant ENC as AES-256 Encryption participant DB as Database participant OP as Operator V->>UI: Submit voice/text via NHAA channel UI->>UI: Record digital consent UI->>API: POST /api/v1/assess/voice or /text API->>PII: Anonymize PII (Aadhaar, Phone, Names) PII->>API: Redacted text returned API->>AI: Run Voice Pipeline (Whisper STT, Acoustic, Emotion) API->>AI: Run Text Pipeline (Language, Translation, Trauma, Sentiment, SI) AI->>API: Component scores returned API->>API: Compute SVI (0-100), Categorize Risk, Generate Interventions API->>ENC: Encrypt sensitive fields (AES-256) ENC->>DB: Store Case + Assessment + Interventions API->>DB: Create Audit Log Entry API->>UI: Return SVI score, risk level, recommendations UI->>OP: Display on Operator Dashboard opt CRITICAL Risk UI->>OP: Red Alert Banner + PCR Dispatch Recommendation end
